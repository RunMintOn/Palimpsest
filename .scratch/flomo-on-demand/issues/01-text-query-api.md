# 01: Palimpsest 独立文本查询入口

**What to build:** 外部插件无需打开编辑器或侧边栏，即可用文本及候选文件集合查询已有索引，取得文件级命中原文或明确错误，不触发正式索引更新。

**Blocked by:** None (can start immediately).

**Status:** resolved

## Context

共同约定见 [第一版 spec](../spec.md)。本票归 Palimpsest 仓库。Flomo 的 02 可依据同一协议并行使用模拟结果开发，真实连接由 03 验收。与 Markdown 结构修正任务无硬依赖。

## Acceptance criteria

- [x] 提供 spec 定义的 retrievalApi、apiVersion = 1 和 query 普通对象协议，输入、结果及错误代码一致；不暴露数据库、chunk ID、向量或 Obsidian 类实例。
- [x] 先写公开入口回归，再实现无编辑器、无侧边栏可见性依赖的文本查询；不修改原侧边栏来源、调度或展示语义。
- [x] 输入校验覆盖空白文本、16,000 字符上限、非法 limit、非法 Vault 路径；空 candidatePaths 明确为空，不回退全库。
- [x] 来源未索引仍可作为文本查询；候选与实际索引范围取交集，排除 sourcePath 的全部片段。
- [x] 用候选外高排名片段和同文件大量片段的测试，证明过滤在召回／截断过程中生效；每文件取最佳片段，按其融合排名排序，候选不足按有界策略扩展。
- [x] 不建立新文件评分模型；侧边栏原有 maxPerFile 行为保持。结果只包含文件路径与一基、含端点的片段范围及 Markdown 源文。
- [x] 成功零条与错误可区分，knownPendingUpdates 覆盖已知排队、对账、更新、deferred 和范围 pending，不宣称绝对实时。
- [x] query 不启动扫描、文档 embedding、正式索引写入、范围应用或更新确认；允许按需恢复已提交片段的派生关键词缓存。
- [x] 保留正式索引身份校验；暂时不能安全查询时返回 temporarily-unavailable，不为首版实现无阻塞旧代读取。
- [x] 并发外部请求与侧边栏请求互不覆盖；外部调用方丢弃自己的旧响应不能作废共享缓存或别人的查询。索引实际换代、缓存失败及卸载仍有正确屏障。
- [x] 卸载后旧实例及在途调用不能返回新的成功结果；未知错误转换为查询失败，保留可检查的故障信息。
- [x] 覆盖 spec 规定的模型／native 不可用、无索引、不兼容、快照变化及并发场景；复用真实 native 检索测试，不新增通用模拟框架。
- [x] typecheck、全套测试、build 通过；提供 v1 请求／响应说明和本票验证记录，供 02、03 对照。

## Implementation constraints

检索模块与编辑器调度分开，但不把每个阶段变成可插拔接口。不引入服务端、插件总线、状态订阅、缓存持久化或外部索引维护注册。实例生命周期校验和共享关键词同步应采用最小充分方案。

本票完成只证明 Palimpsest 入口可用，不能宣称 Flomo 已接入。禁止正式 Vault 操作、发布、同步或未经要求的提交。

## Completion

已完成 v1 文本查询入口、范围内混合召回、实例／快照屏障和稳定错误。公开入口真实 native 测试 8 项通过；全套 212 项、typecheck 与 build:native 通过。协议说明见 [api-v1](../api-v1.md)，最终证据见 [review](../reviews/final.md)。

用户本轮通过 implement 明确授权完成后提交，覆盖本票早期不提交的默认限制。
